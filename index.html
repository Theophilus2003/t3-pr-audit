How I built this

  • A GitHub Action reruns the audit every 3 hours. It reads the open list from the GitHub API and fetches each PR's branch from refs/pull/N/head.
  • "Merges clean" means git merge-tree --write-tree of the branch into the latest main finished without conflicts. GitHub runs the same three-way merge.
  • "Behind" counts the commits on main since the PR's merge base. "Edits moved files" means the PR changes a path that no longer exists on main.
  • "Nothing left to merge" means the diff is empty, or the whole diff is already applied on main.
  • Overlaps come from PRs that remove the same source lines, cite the same issue, or have near-identical titles on the same files. Stacked PRs that share commits are left out.
  • The hand-picked lanes were read and checked on Oct 18, 2026. Their status chips update on every refresh. No test suites are run.
