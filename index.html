    How I built this

    • The open list is GitHub's own list on Oct 18, 2026, 1,353 PRs. Each PR's branch was fetched from refs/pull/N/head.
    • "Merges clean" means git merge-tree --write-tree of the branch into main at eb7b35a finished without conflicts. GitHub runs the same three-way merge.
    • "Behind" counts the commits on main since the PR's merge base. "Edits moved files" means the PR changes a path that no longer exists on main.
    • "Nothing left to merge" means the diff against main is empty, or the whole diff is already applied on main.
    • Duplicate groups come from PRs that remove the same source lines, cite the same issue, or have near-identical titles on the same files. Stacked PRs that share commits were left out. The "Same bug, several PRs" groups were read by hand.
    • Titles in the table come from each PR's first commit, and names are commit authors. Both usually match GitHub. Review bot verdicts and maintainer comments were read on GitHub for the PRs named in the four lanes only. No test suites were run.
